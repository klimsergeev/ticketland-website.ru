# Структура данных события

## Основная информация
- **id**: `string` — уникальный идентификатор события
  - Пример: `"mamma-mia-moscow"`
- **title**: `string` — название события
  - Пример: `"«МАММА МИМО! или Мюзикл пошёл не так»"`
- **genre**: `string` — жанр
  - Пример: `"Мюзикл"`
- **ageRating**: `number` — возрастной ценз
  - Пример: `16`
- **rating**: `number` — рейтинг (float)
  - Пример: `9.5`
- **reviewsCount**: `number` — количество отзывов
  - Пример: `895`
- **duration**: `string` — продолжительность (HH:MM)
  - Пример: `"01:40"`

## Изображения
- **coverImage**: `string` — обложка события
  - Пример: `"/assets/events/mamma-mia/cover.jpg"`
- **images**: `array[string]` — галерея изображений
  - Пример:
    ```
    [
      "/assets/events/mamma-mia/gallery-1.jpg",
      "/assets/events/mamma-mia/gallery-2.jpg",
      "/assets/events/mamma-mia/gallery-3.jpg"
    ]
    ```

## Описание
- **description**: `object`
  - **short**: `string` — краткое описание
    - Пример: `"Директор завода хочет подарить жене настоящий мюзикл..."`
  - **full**: `string` — полное описание
    - Пример: `"В день премьеры градус безумия достигает предела..."`
  - **video**: `object` — видео (опционально)
    - **url**: `string` — ссылка на видео
    - **thumbnail**: `string` — превью видео
    - **duration**: `string` — длительность видео

## Актёры (cast)
Массив объектов с ссылками на персон и их ролями в событии:
- **personId**: `string` — ID персоны из `/data/persons.json`
  - Пример: `"nikolay-fomenko"`
- **role**: `string` — роль в этом событии
  - Пример: `"Автор"`, `"Актриса"`, `"Актёр"`

### Файл persons.json
Отдельный файл `/data/persons.json` содержит информацию о всех персонах:
```json
{
  "nikolay-fomenko": {
    "id": "nikolay-fomenko",
    "name": "Николай Фоменко",
    "photo": "/assets/persons/nikolay-fomenko.jpg",
    "bio": "Российский актёр, телеведущий, музыкант"
  }
}
```

**Преимущества:**
- Одна персона может участвовать в разных событиях
- Нет дублирования данных (имя, фото, био)
- Легко обновлять информацию о персоне в одном месте

## Организатор
- **organizer**: `object`
  - **name**: `string` — название организации
    - Пример: `"ООО \"Культурная служба\""`
  - **inn**: `string` — ИНН
    - Пример: `"7707719297"`
  - **erir**: `string` — ЕРИР ID
    - Пример: `"Pb3XmBtzszTf4IICf2KPZJVjgvq3vIU6tikW776"`

## Сеансы (sessions)
Массив объектов с информацией о сеансах:
- **id**: `string` — уникальный ID сеанса
  - Пример: `"2024-09-07-14-30"`
- **date**: `string` — дата в формате ISO (YYYY-MM-DD)
  - Пример: `"2024-09-07"`
- **time**: `string` — время (HH:MM)
  - Пример: `"14:30"`
- **dayOfWeek**: `string` — день недели (человекочитаемый)
  - Пример: `"сегодня"`, `"завтра"`, `"воскресенье"`
- **dateLabel**: `string` — дата (человекочитаемая)
  - Пример: `"07 сентября"`
- **venue**: `object` — площадка (каждый сеанс может быть на своей площадке)
  - **id**: `string` — ID площадки
    - Пример: `"moscow-youth-palace"`
  - **name**: `string` — название площадки
    - Пример: `"Московский дворец молодёжи"`
  - **type**: `string` — тип площадки
    - Пример: `"Театр"`
  - **city**: `string` — город
    - Пример: `"Москва"`
  - **region**: `string` — регион площадки (показывается если не совпадает с регионом пользователя)
    - Пример: `"Москва"`, `"Санкт-Петербург"`
  - **address**: `string` — адрес
    - Пример: `"Комсомольский пр-т, 28"`
  - **coordinates**: `object` — координаты для карты
    - **lat**: `number` — широта
    - **lng**: `number` — долгота
- **hall**: `string` — название зала
  - Пример: `"Основная сцена"`, `"Малый зал + фойе"`
- **hasTickets**: `boolean` — есть ли билеты в продаже
  - Пример: `true` / `false`
- **priceFrom**: `number|null` — цена от (в рублях)
  - Пример: `800`, `null` (если билетов нет)
- **ticketsLeft**: `number|null` — осталось билетов (если нужно показать)
  - Пример: `2`, `null` (если не показываем количество)

## Отзывы (reviews)
Массив объектов с отзывами:
- **id**: `string` — уникальный ID отзыва
  - Пример: `"review-1"`
- **author**: `object` — автор отзыва
  - **firstName**: `string` — имя
    - Пример: `"Олег"`
  - **lastName**: `string` — фамилия
    - Пример: `"Данилов"`
- **date**: `string` — дата отзыва (YYYY-MM-DD)
  - Пример: `"2024-08-12"`
- **rating**: `number` — оценка (1-5)
  - Пример: `5`
- **badge**: `string` — бейдж отзыва
  - Пример: `"Великолепно"`, `"Хорошо"`
- **badgeColor**: `string` — цвет бейджа
  - Пример: `"green"`, `"yellow"`
- **text**: `string` — текст отзыва
  - Пример: `"Мюзикл просто заворожил! Музыка великолепна..."`

## Промо-баннеры (promos)
Массив объектов с промо-баннерами:
- **id**: `string` — уникальный ID промо
  - Пример: `"promo-buffet"`
- **image**: `string` — путь к изображению баннера
  - Пример: `"/assets/promos/buffet-banner.jpg"`
- **link**: `string` — ссылка при клике на баннер
  - Пример: `"/promo/buffet"`

## Метаданные (meta)
Служебная информация:
- **createdAt**: `string` — дата создания (ISO 8601)
  - Пример: `"2024-01-15T10:00:00Z"`
- **updatedAt**: `string` — дата обновления (ISO 8601)
  - Пример: `"2024-09-07T08:30:00Z"`
- **status**: `string` — статус события
  - Пример: `"active"`, `"draft"`, `"archived"`
- **featured**: `boolean` — избранное событие (для главной страницы)
  - Пример: `true` / `false`

---

## Примечания

1. **Subtitle** (подзаголовок) не хранится в данных — берётся из ближайшего сеанса (venue.name)
2. **Площадка** — это свойство сеанса, т.к. разные сеансы могут проходить в разных городах/площадках
3. **Region** в venue показывается только если регион площадки не совпадает с регионом пользователя (например, показ "Санкт-Петербург" для пользователя из Москвы)
4. **Промо-баннеры** — только изображение и ссылка, без дополнительной детализации
5. Все пути к изображениям относительные от корня проекта
